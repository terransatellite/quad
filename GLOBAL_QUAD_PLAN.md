# quad — the global plan

Versions are quad's global milestones. Each version is a set of languages quad writes, and
quad moves to the next version only once the one before it is accomplished. Version 005 is
the final version: there are no versions after it.

This plan is still being worked out. For now the focus is version 002, English.

## The versions

| version | quad writes | status |
|---|---|---|
| 001 | C++ (the first attempt) | archived in `old_versions/version-001/`, not built. Kept as a reference. |
| 002 | English | **now** |
| 003 | satellite | after 002 |
| 004 | C++ | after 003 |
| 005 | English, satellite, C++, Python, Java, Bash, Rust, HTML/CSS, JavaScript, and whatever else | after 004. The final version. |

## Version 002 — English

- quad writes in English, and only English. That is the extent of version 002.
- quad learns from:
  - Wikipedia,
  - Common Crawl,
  - HTML the author has scraped.
- Once quad's ability to speak English is built up, quad moves on to version 003.

## Where quad runs

- quad runs on the author's hard drive.
- A directory on that drive holds the Wikipedia, Common Crawl and scraped HTML files.
- Those files are not in this GitHub repo. Everything built for version 002 assumes that input
  is available.
